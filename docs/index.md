# PlacePulse

### An unofficial, open-source companion app for BIT Mesra T&P

PlacePulse helps students stay updated with placement opportunities from the BIT Mesra Training & Placement portal.

## What is PlacePulse?

PlacePulse provides a simple way to:

- Browse available placement opportunities
- Track job deadlines
- Receive notifications when new jobs are posted
- Quickly access application links
- View useful placement statistics

PlacePulse is an independent student project and is **not affiliated with or officially endorsed by BIT Mesra**.

## Privacy

PlacePulse does not require users to create an account or provide personal information.
